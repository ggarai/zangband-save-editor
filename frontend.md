Create a web-based frontend for the tool. Main elements:

- File name text box with Browse button, to search and select a save game file
- Encode and Decode buttons for converting the file to and from the editable format
- Text boxes for character properties, with meaningful labels for each (based on the Description field in value-mapping.md). Where a text property is stored as a number (e.g. Class), display the text.
- Load button that populates the text boxes from the decoded file
- Save button that writes the text box values into the decoded file
